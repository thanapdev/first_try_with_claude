# My First Project with Claude

A simple single-page landing page introducing what Claude can do.

## Rules

- Plain HTML, CSS, and JS only — no frameworks, build tools, bundlers, or external libraries/CDNs.
- No build step: open `index.html` directly in a browser to view.

## Files

- `index.html` — page structure and content
- `style.css` — all styling (dark theme, responsive)
- `script.js` — small interactivity (greet button, master reveal)
